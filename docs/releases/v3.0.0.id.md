# v3.0.0 — Verifikasi chat sebelum bertindak

[Semua bahasa](README.md) · [Unduh](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.0.0) · [Instalasi](../quickstart-windows.md) · [Migrasi dan pemulihan](../MIGRATING.md#upgrading-to-v300)

![LINE Agent MCP](../assets/line-agent-cover-v3.png)

Rilis ini memperketat batas chat GUI dan media yang dikembalikan. Nama MCP tetap `line-desktop-mcp`. Windows menyediakan 29 tools opt-in dengan `LINE_MCP_EXTENSIONS=1`, atau lima descriptor bawaan tanpa flag. Nama, urutan, dan skema input tetap sama, tetapi deskripsinya kini menyatakan ketersediaan per platform. Ini versi mayor karena prasyarat GUI Windows dan ketersediaan macOS berubah.

## Perubahan kompatibilitas dan batas

- Setiap jalur GUI Windows untuk chat bernama, termasuk lima tools bawaan, memerlukan CUA, `LINE_MCP_PYTHON` / `LINE_MCP_SQLITE3MC_DLL`, SQLite3MC DLL yang dipasangi pin, serta Python `cryptography` dan Pillow. Status saja tidak membuktikan kesiapan.
- Snapshot metadata-only privat memeriksa group dan direct chat yang ada sebelum menyentuh jendela LINE, tanpa pesan atau media. Nama mentah harus cocok tepat; NFC, spasi, benturan anggota/lintas jenis, dan inventaris tak lengkap gagal secara tertutup.
- Buka chat melalui pengguna atau UI terpandu terverifikasi. `open_line_chat` hanya memverifikasi chat yang sudah terbuka, tidak memilih hasil pertama; header baru tetap harus dibuktikan setelah identitas lokal.
- macOS mencantumkan lima tools bawaan, tetapi riwayat chat, pengiriman, dan file mengembalikan `LINE_CHAT_VERIFICATION_UNAVAILABLE` sebelum automasi. Tidak ada verifier chat atau dukungan operasional macOS.

## Perbaikan keamanan

- Source balasan dan fallback setelah Reply hanya mengembalikan area pesan chat yang diverifikasi. Crop, dimensi PNG, dan fingerprint diperiksa; koordinat dimulai dari asal crop dan bridge melakukan rebase sekali.
- Header segar, chat reference, jenis group/direct, dan piksel mengikat confirmation token. Drift GUI sebelum atau sesudah tindakan menolak atau mengembalikan `operationMayHaveCompleted:true`, tanpa kirim ulang otomatis.
- Riwayat GUI memulihkan format clipboard sebelumnya hanya bila owner serta sequence LINE stabil. Penulis baru dipertahankan dan pembacaan ditolak; Clipboard History, listener, dan race pemulihan tetap menjadi batas.
- APNG hanya mengembalikan frame pertama; source PNG/JPEG statis tidak berubah. JSON terlalu dalam menjadi unknown tanpa menghentikan baris valid. Pembacaan local DB dan metadata polling tetap sama.

## Verifikasi dan batasan

Rilis ini diverifikasi dengan synthetic regression tests Node/Python, engine SQLite3MC yang dipasangi pin, dan parsing AutoHotkey native: 221 Node tests lulus; 101 dari 102 Python tests lulus, satu skip karena symlink Windows.

v3.0.0 tidak mengulang pembacaan chat LINE langsung, clipboard, pengiriman, atau GUI end-to-end. Angka v2.0.0—inti riwayat teks 17.866→4.661 detik, warm read 0.732–0.803 detik, dan pembacaan langsung—adalah bukti historis, bukan benchmark guard GUI v3. Identitas lokal dan piksel UI bukan pengikatan DB ID atomik; perubahan bersamaan tetap menjadi batas.

## Instalasi dan pemulihan

Gunakan source tag GitHub `v3.0.0`, atau lampiran `line-desktop-mcp-3.0.0.tgz` dan `SHA256SUMS.txt`; tidak ada rilis npm registry atau MCPB. Ekstrak lokal, jalankan `npm ci --ignore-scripts`, lalu konfigurasi Node.js 24+, CUA, Python, SQLite3MC DLL, dan AutoHotkey v2 bila perlu. Hubungkan ulang klien MCP dan segarkan schema. Simpan paket serta launcher sebelumnya untuk rollback; akun LINE dan data chat tidak perlu dimigrasikan. [Kontrak lengkap](../windows-extensions.md)
