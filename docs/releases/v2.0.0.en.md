# v2.0.0 — LINE context, including images. Faster reads.

[All languages](README.md) · [Download](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v2.0.0) · [Installation](../quickstart-windows.md)

![Read, summarize, approve, send, check](../assets/workflow-en.svg)

**Bring text and images into the same context, with less waiting.** Select a chat and date range: the reader returns scoped conversation text and, when requested, available cached image previews for an image-capable AI model. The assistant can organize progress and next steps, then show a draft for confirmation before sending. Business files and other services still need their own authorized sources or connectors.

This release provides 29 opt-in Windows tools. Its two main advances are image-inclusive context and faster local reads; the measurements and media limits below define what was actually verified.

## Upgrade from v1.2.0

**Upgrade in the existing repository:** install v2.0.0, add the Python/SQLite3MC reader dependencies, reconnect and refresh tool schemas. The MCP identity stays `line-desktop-mcp`; LINE account/chat data need no migration. [Upgrade and rollback](../MIGRATING.md) `stage_line_reply` now requires the complete `source` and a short-lived, one-use `sourceToken` from the source-observation/confirmation tools. Old text-only reply calls are rejected. `get_line_status` adds independent `localReader` build/process metadata; a missing UI backend does not erase that result. Status is not proof that Python dependencies or the DLL are ready.

LINE Agent MCP is the display name for this Windows community edition. v2.0.0 continues the existing repository and preserves the five original default tools and macOS interface. The opt-in reply schema changes require the major version.

## What is new

- **Scoped local history:** one exact group or direct chat, explicit dates, at most 31 days, literal search, source references, keyset pagination and fresh DB/WAL snapshots. GUI comparison is optional and happens once per requested call.
- **Media when needed:** PNG/JPEG images, bounded GIF/WebP first-frame previews and validated small PCM WAV blocks. Original/thumbnail, missing, deferred and unsupported states stay explicit.
- **Stronger reply and poll workflows:** verify the complete quoted source and current pixels before staging; read an already-open poll only after it is bound to the authorized group. Plans do not send, publish or create real mention tokens.
- **Compatibility and speed:** verified LINE build hashes, process-instance diagnostics, bounded key search, short-lived locator reuse and fewer redundant UI enumerations. Unknown LINE builds fail closed.
- **Five-language documentation:** Traditional Chinese, English, Japanese, Thai and Indonesian, with a new cover and localized workflow graphics.

## Measured on the maintainer's Windows machine

![Cold-reader core: 17.866 to 4.661 seconds](../assets/performance.svg)

The cold-reader core improved from **17.866 to 4.661 seconds**. Warm reads over a persistent MCP connection measured **0.732–0.803 seconds** after restart checks. Client/model overhead is additional; these are not universal latency guarantees.

Two actual LINE restarts were followed by successful scoped reads. Five actual cached images passed MCP transport and independent decoding checks. Broader GIF/WebP/WAV cases use synthetic tests. Other live workflows have separate evidence and do not certify every adapter or locale.

## Requirements and limits

The server requires Node.js 24 LTS or newer (tested: 24.19.0). Local reads require Windows x64, an allowlisted signed-in LINE build, explicit `LINE_MCP_PYTHON` and `LINE_MCP_SQLITE3MC_DLL`, and Python dependencies. UI tools separately use `LINE_MCP_CUA_DRIVER`. Startup does not install dependencies or read chats. Local reading uses bounded read-only access to the signed-in LINE process memory; refused access stops the operation.

Live GUI evidence covers **LINE 26.4.2.3957, Traditional Chinese UI**. Other UI languages are not live-certified. Query dates and poll planning use **Asia/Taipei, UTC+08:00**. Local caches are not a full server archive; there is no universal audio/video playback, transcription or recipient-notification guarantee. Decoding/OCR run locally, while returned tool content is processed according to the chosen AI client's policies.

Use this GitHub source tag or release `.tgz`. No npm-registry or MCPB release is provided. The older `line-desktop-mcp@latest` package does not install this project. [Full contract and verification](../windows-extensions.md)

Timing samples above measure text history, not end-to-end image understanding. Both `cryptography` and Pillow are required for local reads. This release uses stdio only, with explicit MCP client environment settings; HTTP/REST and automatic cwd `.env` loading are removed.
