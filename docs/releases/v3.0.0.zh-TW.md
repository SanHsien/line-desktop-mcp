# v3.0.0 — 先核對聊天室，再讀取與操作

[全部語言](README.md) · [下載](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.0.0) · [安裝](../quickstart-windows.md) · [升級與回退](../MIGRATING.md#upgrading-to-v300)

![LINE Agent MCP](../assets/line-agent-cover-v3.png)

這次安全更新補強 GUI 讀取、草稿與傳送的聊天室驗證，也縮小回傳媒體的範圍。MCP 名稱維持 `line-desktop-mcp`，Windows 可選用 29 個工具，預設列出五個工具。預設工具的名稱、順序與輸入 schema 保留，描述改為反映各平台可用性。由於 Windows GUI 前置條件及 macOS 功能改變，本次升為主要版本。

## 升級前要知道

- Windows 所有指定聊天室的 GUI 路徑，含預設五工具，都需要 CUA 與已設定的 Python／SQLite3MC 本機讀取器；Python 同時需要 `cryptography` 和 Pillow。能力清單或程序狀態不代表依賴全部就緒。
- 接觸 LINE 視窗前，先用私有的中繼資料快照檢查有上限且完整的群組與既有個人對話清單，不讀訊息或媒體。同名、視覺近似名稱、清單不完整或身分無法確認時拒絕；不能靠指定群組／個人類型避開跨類型同名。
- 先手動或經另行核對的引導式 UI 流程開啟指定聊天室。`open_line_chat` 現在只驗證已開啟的聊天室，不再點搜尋第一筆。本機身分唯一後，仍須核對目前標頭。
- macOS 仍列出預設五工具，但讀取／傳送會在自動化前回報 `LINE_CHAT_VERIFICATION_UNAVAILABLE`；本版未提供 macOS 聊天室驗證器。

## 修補內容

- **引用截圖：** 來源選取及點 Reply 後的備援只回傳已驗證的聊天室區域，檢查裁切範圍、PNG 尺寸與指紋，對外座標從裁切圖原點起算。
- **GUI 身分：** 舊版與 extension 共用驗證，確認 token 綁定新查到的 opaque 聊天室參考與類型；身分改變即拒絕。輸入後發現換聊天室會回報 `operationMayHaveCompleted:true`，保留不確定狀態，不自動重送。
- **剪貼簿：** 歷史複製前保存可取得的格式，確認 LINE 擁有者與 sequence，回傳前恢復；若其他程式已寫入則保留新內容並拒絕。此保護無法清除 Clipboard History 或外部觀察者的副本。
- **APNG：** 動畫 PNG 沿用有 byte／pixel 預算的首幀衍生流程，不再回傳完整動畫；靜態 PNG／JPEG bytes 保留。
- **過深 JSON：** 異常巢狀 metadata 不再中斷整頁歷史，回到未知 metadata，保留普通文字與同頁正常資料。

## 驗證範圍

候選程式通過 Node／Python 合成回歸、固定版本 SQLite3MC 原生測試及 AHK 原生語法解析，涵蓋同名、過期 token、剪貼簿保護、裁切錯誤、APNG、深 JSON 與正常對照。下載附 SHA-256；GitHub 發行頁列出最終乾淨套件的測試數。

這次未重做實際 LINE 聊天讀取、剪貼簿互動或傳送。v2.0.0 的速度與實機操作紀錄是歷史證據，不能當作 v3.0.0 的新量測。本機身分快照與 UI 像素並非原子的資料庫 ID 綁定，兩次觀察之間的併發變動仍有限制。工具回傳內容仍依使用的 AI 客戶端及模型設定處理。

## 安裝與回退

使用 GitHub `v3.0.0` tag 或附帶的 `.tgz`，本專案未發布至 npm registry 或 MCPB。解壓縮到新的本機目錄，執行 `npm ci --ignore-scripts`；使用 Node.js 24+，明確設定 `LINE_MCP_PYTHON`、`LINE_MCP_SQLITE3MC_DLL`、`LINE_MCP_CUA_DRIVER`，需要的 GUI 路徑另設定 AutoHotkey v2。切換後重新連線 MCP 並刷新 schema。保留舊套件與啟動器供回退，但回退也會恢復舊版安全行為。LINE 帳號與聊天資料不需搬移。

本版維持本機 stdio；啟動不會安裝依賴、讀取聊天或載入目前目錄的 `.env`。日期範圍仍採 Asia/Taipei（UTC+08:00），一次最多 31 天；本機快取不是完整伺服器歷史。[完整工具契約](../windows-extensions.md)
