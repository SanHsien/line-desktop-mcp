# v2.0.0 — บริบท LINE ที่รวมรูปภาพด้วย อ่านเร็วขึ้น

[ทุกภาษา](README.md) · [ดาวน์โหลด](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v2.0.0) · [การติดตั้ง](../quickstart-windows.md)

![อ่าน สรุป อนุมัติ ส่ง และตรวจสอบ](../assets/workflow-th.svg)

**นำข้อความและรูปภาพมาอยู่ในบริบทเดียวกัน พร้อมลดเวลารอ** เลือกแชตและช่วงวันที่ แล้ว reader จะคืนข้อความการสนทนาตามขอบเขต และเมื่อร้องขอ จะคืน preview ของรูปภาพที่มีอยู่ในแคชให้โมเดล AI ที่รองรับภาพ ผู้ช่วยสามารถจัดระเบียบความคืบหน้าและขั้นตอนถัดไป แล้วแสดงร่างข้อความเพื่อยืนยันก่อนส่ง ไฟล์ธุรกิจและบริการอื่นยังต้องใช้แหล่งข้อมูลหรือ connector ที่ได้รับอนุญาตของตนเอง

รุ่นนี้มี 29 opt-in tools สำหรับ Windows ความก้าวหน้าหลักสองอย่างคือบริบทที่รวมรูปภาพ และการอ่านในเครื่องที่เร็วขึ้น ตัวเลขการวัดและข้อจำกัดของสื่อด้านล่างระบุขอบเขตที่ตรวจสอบจริง

## การอัปเกรดจาก v1.2.0

**อัปเกรดใน repository เดิม** สำรองการตั้งค่า MCP client ปัจจุบันก่อน จากนั้นอัปเดต checkout `line-desktop-mcp` เดิมเป็น v2.0.0 หรือรับ v2.0.0 ลงในไดเรกทอรี source แยกต่างหากแล้วเปลี่ยนปลายทางของ client เพิ่ม dependencies สำหรับ Python/SQLite3MC reader เชื่อมต่อใหม่ และรีเฟรช tool schema ตัวระบุ MCP ยังคงเป็น `line-desktop-mcp` และไม่ต้องย้ายบัญชี LINE หรือข้อมูลแชต [การอัปเกรดและย้อนกลับ](../MIGRATING.md)

`stage_line_reply` ต้องใช้ `source` แบบเต็มและ `sourceToken` แบบอายุสั้น ใช้ได้ครั้งเดียว จาก tools สำหรับสังเกต/ยืนยันต้นทาง การเรียกตอบกลับแบบข้อความอย่างเดียวเดิมจะถูกปฏิเสธ จึงต้องแก้ไข caller `get_line_status` เพิ่ม metadata ของ build/process ใน `localReader` ที่เป็นอิสระ แม้ไม่มี UI backend ผลลัพธ์นี้จะยังไม่หายไป แต่สถานะไม่ได้ยืนยันว่า Python dependencies หรือ DLL พร้อมใช้งานแล้ว

LINE Agent MCP เป็นชื่อที่ใช้แสดงของรุ่นชุมชน Windows นี้ v2.0.0 สืบต่อ repository เดิม และคง 5 tools ค่าเริ่มต้นเดิมกับอินเทอร์เฟซ macOS ไว้ การเปลี่ยน schema ตอบกลับแบบ opt-in ต้องใช้ major version

## สิ่งใหม่

- **ประวัติในเครื่องตามขอบเขต:** แชตกลุ่มหรือแชตส่วนตัวที่ตรงกันเพียงหนึ่งรายการ วันที่ชัดเจน สูงสุด 31 วัน การค้นหาแบบ literal source reference การแบ่งหน้าแบบ keyset และ DB/WAL snapshot ใหม่ การเปรียบเทียบ GUI เป็นตัวเลือกและทำเพียงครั้งเดียวต่อคำขอ
- **สื่อเมื่อต้องการ:** รูป PNG/JPEG preview เฟรมแรกของ GIF/WebP ที่มีขอบเขต และบล็อก PCM WAV ขนาดเล็กที่ผ่านการตรวจสอบ สถานะ original/thumbnail, missing, deferred และ unsupported ยังคงระบุชัดเจน
- **เวิร์กโฟลว์ตอบกลับและโพลที่เข้มแข็งขึ้น:** ตรวจสอบ quoted source แบบเต็มและ pixel ปัจจุบันก่อน stage อ่านโพลที่เปิดอยู่แล้วได้หลังผูกกับกลุ่มที่ได้รับอนุญาตเท่านั้น แผนงานจะไม่ส่ง เผยแพร่ หรือสร้าง mention token จริง
- **ความเข้ากันได้และความเร็ว:** แฮช build LINE ที่ตรวจสอบแล้ว การวินิจฉัย process instance การค้นหาคีย์แบบมีขอบเขต การใช้ locator อายุสั้นซ้ำ และการลดการไล่ดู UI ที่ซ้ำซ้อน build LINE ที่ไม่รู้จักจะ fail closed
- **เอกสาร 5 ภาษา:** Traditional Chinese, English, Japanese, Thai และ Indonesian พร้อมภาพปกใหม่และ workflow graphic เฉพาะภาษา

## วัดบนเครื่อง Windows ของผู้ดูแล

![แกน cold reader: 17.866 เป็น 4.661 วินาที](../assets/performance.svg)

แกน cold reader ดีขึ้นจาก **17.866 เป็น 4.661 วินาที** การอ่านแบบ warm ผ่าน persistent MCP connection วัดได้ **0.732–0.803 วินาที** หลังการตรวจสอบ restart โดย client/model overhead เป็นเวลาเพิ่มเติม จึงไม่ใช่การรับประกัน latency สำหรับทุกเครื่อง

ค่า 17.866 → 4.661 วินาทีเป็นการวัด Python core ของ **ประวัติข้อความ** ตามขอบเขต ไม่รวมการถอดรหัส image preview หรือ overhead ของ model/GUI จึงไม่ใช่ latency แบบ end-to-end สำหรับการทำความเข้าใจภาพ build gate ถูกเพิ่มหลัง cold comparison และการตรวจแยกใช้เวลาประมาณ 24 ms; ค่า warm 0.732–0.803 วินาทีรวม build gate แล้ว

มีการ restart LINE จริง 2 ครั้งตามด้วยการอ่านตามขอบเขตสำเร็จ รูปภาพในแคชจริง 5 รูปผ่านการส่งผ่าน MCP และการถอดรหัสตรวจสอบอิสระ กรณี GIF/WebP/WAV ที่กว้างขึ้นใช้ synthetic test เวิร์กโฟลว์จริงอื่นมีหลักฐานแยกต่างหาก และไม่ได้รับรองทุก adapter หรือทุก locale

## ข้อกำหนดและขอบเขต

เซิร์ฟเวอร์ต้องใช้ Node.js 24 LTS ขึ้นไป (ทดสอบแล้ว: 24.19.0)

การอ่านในเครื่องต้องใช้ Windows x64, LINE build ที่ลงชื่อเข้าใช้และอยู่ใน allowlist, `LINE_MCP_PYTHON` และ `LINE_MCP_SQLITE3MC_DLL` ที่ระบุชัดเจน และ Python dependencies ซึ่งรวม `cryptography` กับ Pillow Pillow จำเป็นต่อการใช้ local reader ทุกแบบ รวมถึงคำขอ metadata only ไม่ได้จำเป็นเฉพาะ preview เครื่องมือ UI ใช้ `LINE_MCP_CUA_DRIVER` แยกต่างหาก การเริ่มต้นจะไม่ติดตั้ง dependency หรืออ่านแชต การอ่านในเครื่องใช้การเข้าถึงแบบอ่านอย่างเดียวที่มีขอบเขตต่อหน่วยความจำ process ของ LINE ที่ลงชื่อเข้าใช้ และจะหยุดเมื่อการเข้าถึงถูกปฏิเสธ

เซิร์ฟเวอร์ทำงานผ่าน local stdio เท่านั้น ไม่ใช่บริการ HTTP/REST หรือบริการ cloud แบบมีค่าใช้จ่าย และจะไม่โหลด `.env` ใน current working directory โดยอัตโนมัติ การตั้งค่ามาจาก environment variables ที่ MCP client ส่งมาอย่างชัดเจน

หลักฐาน GUI จริงครอบคลุม **LINE 26.4.2.3957, Traditional Chinese UI** ภาษา UI อื่นยังไม่ได้รับการรับรองจากการทดสอบจริง วันที่ query และการวางแผนโพลใช้ **Asia/Taipei, UTC+08:00** local cache ไม่ใช่ server archive ทั้งหมด และไม่มีการรับประกันการเล่นเสียง/วิดีโอ การถอดเสียง หรือการแจ้งผู้รับแบบทั่วไป การไม่พบรูปในเครื่องไม่ได้หมายความว่าการประมวลผล AI ทำงานแบบออฟไลน์ และโมเดลที่รองรับภาพจะได้รับเฉพาะ preview จากแคชที่มีอยู่ การถอดรหัส/OCR ทำในเครื่อง ขณะที่เนื้อหาจาก tool ที่ส่งกลับจะถูกจัดการตามนโยบายของ AI client ที่เลือกใช้

ใช้ GitHub source tag นี้หรือ release `.tgz` ไม่มีการเผยแพร่บน npm registry หรือ MCPB แพ็กเกจเก่า `line-desktop-mcp@latest` จะไม่ติดตั้งโครงการนี้ [ข้อกำหนดและการตรวจสอบฉบับเต็ม](../windows-extensions.md)
