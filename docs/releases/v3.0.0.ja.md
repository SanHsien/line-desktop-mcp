# v3.0.0 — 操作前にチャットを検証

[すべての言語](README.md) · [ダウンロード](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v3.0.0) · [インストール](../quickstart-windows.md) · [移行とロールバック](../MIGRATING.md#upgrading-to-v300)

![LINE Agent MCP](../assets/line-agent-cover-v3.png)

このセキュリティリリースは、GUI による読み取り、下書き、送信でチャット境界を厳格にし、返すメディアを絞り込みます。MCP 名は `line-desktop-mcp` のままです。Windows では `LINE_MCP_EXTENSIONS=1` により 29 個の opt-in ツールを使え、設定しない場合は既存の 5 個の標準ツールが記述子として残ります。5 個の名前、順序、入力スキーマは変わりませんが、説明はプラットフォームごとの可用性を示します。Windows GUI の前提条件と macOS の利用可否が変わるため、メジャーバージョンです。

## 互換性と境界の変更

- 標準 5 ツールを含む Windows の名前付きチャット GUI 経路すべてに、CUA、明示的な `LINE_MCP_PYTHON` / `LINE_MCP_SQLITE3MC_DLL`、固定 SQLite3MC DLL、Python の `cryptography` と Pillow が必要です。状態や能力の一覧だけでは、これらが利用可能である証拠になりません。
- 非公開のメタデータ専用スナップショットは、LINE ウィンドウに触れる前に、グループと既存ダイレクトチャットの限定集合を確認します。メッセージやメディアは読みません。生の表示名は完全一致が必要です。NFC 同値、空白の圧縮／トリム、メンバー数付きの衝突パターン、未完全な一覧、種別をまたぐ衝突はすべて安全側に拒否します。
- 対象チャットは最初にユーザーまたは別途検証済みのガイド付き UI 手順で開いてください。`open_line_chat` はすでに開いているチャットを検証するだけで、検索結果の先頭を選びません。ローカルの同定後にも、新しいヘッダー確認が必要です。
- macOS は標準 5 ツールを表示しますが、チャット履歴の読み取り、送信、ファイル操作は自動化前に `LINE_CHAT_VERIFICATION_UNAVAILABLE` で拒否されます。このリリースは macOS のチャット検証や運用サポートを提供しません。

## セキュリティ修正

- 返信ソースと Reply 後のフォールバック画像は、検証済みチャットのメッセージ領域だけを返します。切り抜きのサイズとフィンガープリントを確認し、公開座標は切り抜き画像の原点から始まります。ブリッジは内部で一度だけ座標を再ベースします。
- 新しいヘッダー、チャット参照、グループ／ダイレクト種別、観測ピクセルが確認トークンを結び付けます。GUI 前後でドリフトを検出すると、試行後でも拒否または `operationMayHaveCompleted:true` の不確実な結果を返し、自動再送はしません。
- GUI 履歴コピーは、LINE が所有したクリップボードの形式とシーケンスを確認し、別の書き込みがなければ以前の利用可能な形式を復元します。新しい書き込みは保持して読み取りを拒否します。Clipboard History、外部リスナー、比較／復元の小さな競合は残ります。
- APNG は最初のフレームだけを返し、静的 PNG/JPEG のソースは変更しません。深すぎる JSON メタデータは不明として無視し、同じページの有効なほかの行は続けて処理します。既存のローカル DB 読み取りと投票メタデータの挙動は維持します。

## 検証と制限

このリリースは、合成 Node/Python 回帰テスト、固定 SQLite3MC エンジン、ネイティブ AutoHotkey 構文解析で確認しました。最終結果は Node テスト 221 件成功、Python テスト 102 件中 101 件成功、Windows ファイルシステムの symlink による 1 件 skip です。曖昧な名前、期限切れトークン、クリップボード保護、切り抜き失敗、APNG、深い JSON を対象にしています。

実際の LINE チャット読み取り、クリップボード操作、送信、GUI エンドツーエンドは v3.0.0 では実行していません。v2.0.0 の 17.866→4.661 秒のテキスト履歴コア、0.732–0.803 秒のウォーム読み取り、実機読取は過去の根拠であり、新しい GUI ガードのベンチマークではありません。ローカル同定と UI ピクセルは原子的な DB ID 結合ではないため、観測間の並行変更は残る制限です。

## インストールとロールバック

GitHub の `v3.0.0` ソースタグ、または添付の `line-desktop-mcp-3.0.0.tgz` と `SHA256SUMS.txt` を使用します。npm レジストリや MCPB の配布はありません。新しいローカルディレクトリへ展開して `npm ci --ignore-scripts` を実行し、Node.js 24 以降、CUA、Python、SQLite3MC DLL、必要なら AutoHotkey v2 を明示的に設定してください。MCP クライアントを再接続してスキーマを更新し、以前のパッケージとランチャーはロールバック用に残します。LINE アカウントやチャットデータの移行は不要です。[完全な仕様](../windows-extensions.md)
