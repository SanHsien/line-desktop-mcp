# v2.0.0 — Konteks LINE, termasuk gambar. Pembacaan lebih cepat.

[Semua bahasa](README.md) · [Unduh](https://github.com/bensonmaxai/line-desktop-mcp/releases/tag/v2.0.0) · [Instalasi](../quickstart-windows.md)

![Baca, rangkum, setujui, kirim, periksa](../assets/workflow-id.svg)

**Satukan teks dan gambar dalam konteks yang sama, dengan waktu tunggu lebih singkat.** Pilih chat dan rentang tanggal: reader mengembalikan teks percakapan yang dibatasi cakupannya dan, bila diminta, pratinjau gambar cache yang tersedia kepada model AI yang mendukung gambar. Asisten dapat menata progres dan langkah berikutnya, lalu menampilkan draf untuk konfirmasi sebelum mengirim. Berkas bisnis dan layanan lain tetap memerlukan sumber data atau connector yang diizinkan sendiri.

Rilis ini menyediakan 29 opt-in tools Windows. Dua kemajuan utamanya adalah konteks yang menyertakan gambar dan pembacaan lokal yang lebih cepat; pengukuran serta batas media di bawah menetapkan apa yang benar-benar telah diverifikasi.

## Peningkatan dari v1.2.0

**Tingkatkan dalam repository yang ada.** Cadangkan terlebih dahulu konfigurasi klien MCP saat ini. Kemudian perbarui checkout `line-desktop-mcp` yang ada ke v2.0.0, atau ambil v2.0.0 ke direktori source terpisah dan ubah tujuan klien. Tambahkan dependensi reader Python/SQLite3MC, hubungkan ulang, lalu segarkan tool schema. Identitas MCP tetap `line-desktop-mcp`; akun LINE dan data chat tidak perlu dimigrasikan. [Peningkatan dan pemulihan](../MIGRATING.md)

`stage_line_reply` kini memerlukan `source` lengkap dan `sourceToken` berumur singkat serta sekali pakai dari tools observasi/konfirmasi sumber. Panggilan balasan lama yang hanya memuat teks ditolak sehingga caller harus diperbarui. `get_line_status` menambahkan metadata build/proses `localReader` yang terpisah; hasil tersebut tidak hilang hanya karena backend UI tidak tersedia, tetapi status bukan bukti bahwa dependensi Python atau DLL siap.

LINE Agent MCP adalah nama tampilan untuk edisi komunitas Windows ini. v2.0.0 meneruskan repository yang ada serta mempertahankan lima tools default asli dan antarmuka macOS. Perubahan schema balasan opt-in memerlukan versi mayor.

## Yang baru

- **Riwayat lokal berbatas:** tepat satu chat grup atau direct, tanggal eksplisit, paling lama 31 hari, pencarian literal, source reference, pagination keyset, serta snapshot DB/WAL yang baru. Perbandingan GUI bersifat opsional dan dilakukan satu kali per permintaan.
- **Media saat diperlukan:** gambar PNG/JPEG, pratinjau frame pertama GIF/WebP yang dibatasi, dan blok PCM WAV kecil yang divalidasi. Status original/thumbnail, hilang, ditunda, dan tidak didukung tetap eksplisit.
- **Alur kerja balasan/polling yang lebih kuat:** verifikasi quoted source lengkap dan piksel saat ini sebelum staging; baca polling yang sudah terbuka hanya setelah terikat pada grup yang diizinkan. Rencana tidak mengirim, memublikasikan, atau membuat token mention nyata.
- **Kompatibilitas dan kecepatan:** hash build LINE terverifikasi, diagnostik instance proses, pencarian kunci berbatas, penggunaan ulang locator berumur pendek, dan lebih sedikit enumerasi UI berlebihan. Build LINE yang tidak dikenal gagal secara tertutup.
- **Dokumentasi lima bahasa:** Traditional Chinese, English, Japanese, Thai, dan Indonesian, dengan sampul baru serta grafik alur kerja yang dilokalkan.

## Diukur pada mesin Windows pengelola

![Inti cold reader: 17.866 ke 4.661 detik](../assets/performance.svg)

Inti cold reader meningkat dari **17.866 menjadi 4.661 detik**. Pembacaan warm melalui koneksi MCP persisten terukur **0.732–0.803 detik** setelah pemeriksaan restart. Overhead klien/model merupakan tambahan; ini bukan jaminan latensi universal.

Angka 17.866 → 4.661 detik mengukur core Python untuk **riwayat teks** berbatas; angka ini tidak mencakup dekode pratinjau gambar maupun overhead model/GUI. Ini bukan latensi end-to-end untuk pemahaman gambar. Build gate diintegrasikan setelah perbandingan cold, dengan pemeriksaan terpisah sekitar 24 ms; pembacaan warm 0.732–0.803 detik sudah mencakup build gate.

Dua restart LINE nyata diikuti pembacaan berbatas yang berhasil. Lima gambar cache nyata melewati transport MCP dan pemeriksaan dekode independen. Kasus GIF/WebP/WAV yang lebih luas memakai pengujian sintetis. Alur kerja langsung lain memiliki bukti terpisah dan tidak mengesahkan setiap adapter atau locale.

## Persyaratan dan batasan

Server memerlukan Node.js 24 LTS atau lebih baru (teruji: 24.19.0).

Pembacaan lokal memerlukan Windows x64, build LINE yang sudah masuk dan ada dalam allowlist, `LINE_MCP_PYTHON` serta `LINE_MCP_SQLITE3MC_DLL` yang eksplisit, dan dependency Python termasuk `cryptography` serta Pillow. Pillow diperlukan untuk setiap penggunaan local reader, termasuk permintaan metadata-only, bukan hanya untuk pratinjau. Tools UI memakai `LINE_MCP_CUA_DRIVER` secara terpisah. Startup tidak memasang dependency atau membaca chat. Pembacaan lokal memakai akses baca-saja berbatas ke memori proses LINE yang sedang masuk, dan berhenti bila akses ditolak.

Server hanya berjalan melalui stdio lokal; bukan layanan HTTP/REST atau layanan cloud berbayar. Server tidak memuat `.env` dari direktori kerja saat ini secara otomatis; konfigurasi berasal dari variabel lingkungan yang diberikan secara eksplisit oleh klien MCP.

Bukti GUI langsung mencakup **LINE 26.4.2.3957, Traditional Chinese UI**. Bahasa UI lain belum tersertifikasi secara langsung. Tanggal query dan perencanaan polling memakai **Asia/Taipei, UTC+08:00**. Cache lokal bukan arsip server lengkap; tidak ada jaminan pemutaran audio/video, transkripsi, atau notifikasi penerima universal. Gambar yang tidak ditemukan secara lokal tidak berarti pemrosesan AI berjalan offline, dan model yang mendukung gambar hanya menerima pratinjau cache yang tersedia. Dekode/OCR berjalan lokal, sedangkan konten tools yang dikembalikan diproses mengikuti kebijakan klien AI yang dipilih.

Gunakan source tag GitHub ini atau release `.tgz`. Tidak ada rilis npm registry atau MCPB. Paket lama `line-desktop-mcp@latest` tidak memasang proyek ini. [Kontrak dan verifikasi lengkap](../windows-extensions.md)
